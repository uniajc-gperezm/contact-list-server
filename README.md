# Contact List

A contact list application with localStorage and Express API versions.

## Versions

- **Original**: Uses `main.js` with localStorage (browser-based)
- **API**: Uses `main-api.js` with Express API backend

## Quick Start (API Version)

```bash
npm init -y
npm install express cors
node server.js
```

Then open `http://localhost:3000`
